UPDATE KATEGORI BISNIS MANUAL — PORTAL IKADIS

Fitur yang dipastikan tersedia:
1. Pada formulir Pendataan Alumni, ketika alumni memilih memiliki bisnis, muncul pilihan "Kategori utama bisnis".
2. Pada formulir Perbarui Profil, kategori bisnis lama ditampilkan dan dapat diganti secara manual.
3. Nama bisnis, deskripsi, akun Instagram, dan izin publikasi tetap tersedia.
4. Kategori disimpan pada kolom alumni.kategori_bisnis di Supabase.
5. Kategori ikut ditampilkan dan digunakan pada Direktori Bisnis Alumni.

URUTAN PEMASANGAN
1. Jalankan supabase-schema.sql di Supabase SQL Editor.
2. Ganti index.html dan app.js di repository dengan file dari paket ini.
3. styles.css tidak diubah secara visual; file disertakan agar paket lengkap dan konsisten.
4. Pastikan assets/ikadis-preview.jpg tetap berada pada folder assets.
5. Tunggu deployment Vercel selesai, lalu uji form pendataan dan pembaruan profil.

CATATAN
- Jangan mengubah nama file app.js.
- SQL tidak menghapus data alumni lama.
- Pilihan kategori wajib hanya saat alumni memilih memiliki bisnis.
